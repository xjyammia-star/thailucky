# Thailucky（选号助手）

泰国政府彩票的家庭娱乐选号工具。命理选号只是仪式感与娱乐，不代表预测，也不会提高中奖概率。

## 当前版本：第 1 步（项目骨架）

已完成：
- 登录（账号 + 密码），首次使用时创建管理员账号
- 管理页：管理员给家人创建账号、重置密码、删除账号
- 设置页：出生日期、出生时间、出生城市、手动喜用五行、幸运数字、修改密码
- 首页：下一期开奖倒计时
- 每个人的生辰信息互相独立，管理员也看不到

## 部署步骤（按顺序做）

1. 把本文件夹里的所有文件放进本地的 Thailucky 文件夹，上传到 GitHub 仓库 Thailucky。
   （不要上传 node_modules 和 dist 文件夹，本压缩包里本来就没有。）
2. 打开 Vercel → Add New → Project → 选择 GitHub 仓库 Thailucky → Deploy。
   Framework 会自动识别为 Vite，其他保持默认。第一次部署出来页面会提示"还没有连接数据库"，这是正常的。
3. 在 Vercel 的项目页面：Storage → Create Database → 选择 Neon → 创建并连接到这个项目。
   连接成功后，Vercel 会自动添加环境变量 `DATABASE_URL`，不用手动填。
4. Settings → Environment Variables，手动添加两个：
   - `SESSION_SECRET`：登录加密用的密钥，随便填一长串字符（至少16位，越乱越好，例如 32 位字母数字混合）。
   - `SETUP_CODE`：首次创建管理员账号时要输入的"设置口令"，自己定一个，别人不知道就行。
5. Deployments → 最新一次部署右边的「…」→ Redeploy（让新增的环境变量生效）。
6. 打开网站，会看到"首次设置：创建管理员账号"，输入设置口令、用户名、密码，进入后数据库会自动建好表。
7. 进入【管理】页，给家人创建账号，把用户名和初始密码告诉他们；他们登录后可以在【设置】里自己改密码。

## 以后升级

每一步新增功能如果需要新表，我会提醒你：升级部署完成后，进入【管理】页点一下"更新数据库结构"。
重复点击是安全的，不会删除任何已有数据。
